# Hướng dẫn mở dự án PowerDesigner 16.7

## 🛠 Yêu cầu phần mềm
- SAP **PowerDesigner 16.7**

## 📁 Cấu trúc thư mục dự án
Dự án được lưu trữ trong thư mục `diagram/`, bao gồm:
- File dự án chính có đuôi `.prj`
- Các mô hình kèm theo: Conceptual Model (CDM), Physical Model (PDM),...

## 🚀 Cách mở dự án

1. Mở phần mềm **SAP PowerDesigner 16.7**.

2. Trong PowerDesigner, chọn **File > Open Project...**

3. Truy cập vào thư mục `diagram/`, chọn file có đuôi `.prj` (ví dụ: `du_an_mau.prj`) và nhấn **Open**.

4. Sau khi dự án được mở, trong khu vực **Workspace (khung bên trái)**, bạn sẽ thấy các biểu tượng mô hình.

5. Nhấn đúp vào biểu tượng có tên là **Conceptual Model** để mở mô hình khái niệm (CDM) của dự án.

## 💡 Lưu ý
- Nếu bạn không thấy biểu tượng Conceptual Model, hãy đảm bảo rằng dự án đã được tải hoàn toàn.
- Có thể bật tab "Browser" hoặc "Workspace" nếu không thấy khung hiển thị mô hình.

---

Nếu có bất kỳ vấn đề nào khi mở dự án, vui lòng kiểm tra lại phiên bản phần mềm hoặc đảm bảo rằng file `.prj` chưa bị hỏng hoặc liên hệ với nhóm để hỗ trợ.
